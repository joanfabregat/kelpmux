# KelpClient

The portable terminal client crate in the [KelpCore workspace](../../README.md), shared by the KelpMux TUI and the KelpMux and KelpHub web clients. This is a Rust library and WASM module, not a running service.

It handles client screen snapshots, incremental updates, revision tracking, framing (JSON records and the binary screen records of `binary-screens`), selection and Unicode-aware history layout. Portable wire types and validation come from the [`kelpclient-protocol`](../protocol) crate, and PTYs and authoritative emulation from [`kelpserver`](../server); both live in this repository, so the client core always uses the protocol of the same revision. Browser rendering, SSH authentication, fonts, clipboard integration and application presentation stay outside this core; the browser side is the [`@kelpcore/web`](../../web) layer.

`Client::receive` accepts both screen formats. On a connection that enabled [`binary-screens`](../server/docs/binary-screens.md), it holds each update marked `binary_screens` until the binary record after it, decodes that record with `kelpclient_protocol::screens::decode` (bounded by the Welcome's `limits.subscribed_cells`) and applies its screens exactly as JSON screens. It returns the update with those screens as JSON `snapshots` and `patches` (a binary patch becomes a cell patch of every cell of its rows) and without `binary_screens`, so callers, and the browser layer above the WASM module, see one format. A record without its update, a JSON record where a record is due, or a record that fails to decode is a protocol error. The client never sends the opt-in itself; the caller sends `binary_screens` when Welcome lists the capability.

Build from the workspace root with `cargo build -p kelpclient --release --locked --target wasm32-unknown-unknown`. Install that Rust target first. Applications serve the resulting `kelpclient.wasm` as `client-core.wasm`, built from the same KelpCore revision as the server it talks to. Preserve protocol compatibility when changing either side.
