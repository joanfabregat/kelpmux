# Additional appearance assets

Cobalt2 and Apple System Colors are copied exactly from the local Rootshell `Resources/themes` definitions. Rootshell is copyright © 2026 Rootshell LLC, Kit Knox, under the MIT license, included at `public/licenses/Rootshell-MIT.txt`. These are the dark variants. The Cobalt2 light variant is derived from that Rootshell palette (same hues, darkened for a light background) and remains under its MIT license; the Black light variant is KelpMux's own. The Apple System Colors light variant uses Apple's light-appearance system colour values as published in Apple's Human Interface Guidelines (Color → System colors); `src/appearance.ts` lists which value each ANSI colour uses and which were darkened for contrast.

The following terminal themes copy upstream color palettes without modification (`src/appearance.ts`, marked `upstream`). Only the 16 ANSI colors, background, foreground and, where listed, cursor, cursor-text, selection and selected-text colors are used; where a scheme defines no cursor or selection color, KelpMux uses the foreground as cursor and tints the background with the scheme's blue for selection. Interface colors derived from them (surfaces, interface text, accent) are computed by KelpMux and are not part of the upstream schemes. Some upstream light variants are below the 3:1 ANSI contrast that KelpMux's own light palettes meet; they are kept as published.
