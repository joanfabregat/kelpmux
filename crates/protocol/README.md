# Kelp terminal protocol

Portable terminal wire types, version constants and cell validation shared by the [server](../server) and [Rust/WASM client](../client) in the [KelpMux workspace](../../README.md). This crate has no client presentation or WASM dependency. Terminal stream version 1 and local protocol version 58 remain unchanged by consolidation.

See [stream documentation](../server/docs/native-client-protocol.md), [contribution policy](../../CONTRIBUTING.md), [security policy](../../SECURITY.md) and the workspace [Apache-2.0 license](../../LICENSE).
