# Independent terminal stream

The canonical [terminal stream contract](https://github.com/joanfabregat/kelpcore/blob/main/crates/server/docs/native-client-protocol.md) lives in the [KelpCore repository](https://github.com/joanfabregat/kelpcore). The local composed-screen protocol is version 58; the independent terminal stream remains version 1. KelpMux builds against the KelpServer revision pinned in `Cargo.toml`, and its portable wire types (`kelpclient-protocol`) come from that same revision. See [MIGRATION.md](../MIGRATION.md) for workspace ownership and compatibility boundaries.

When the server offers `binary-screens`, the TUI and the web client opt in and receive pane screens as binary records, each directly after its `update` ([format](https://github.com/joanfabregat/kelpcore/blob/main/crates/server/docs/binary-screens.md)): the TUI decodes them natively with `kelpclient_protocol::screens` (`tui::attach::Records`), the web client in its WASM core, and `kelpmux web-bridge` forwards them to the browser unchanged ([web.md](web.md)). Every other record, including everything clients send, stays length-prefixed JSON, and connections that do not opt in (`kelpmux ctl` and the bridge's own `Web` operations) receive only JSON.
